API reference

The ShoutKit SDK surface

DocC-generated reference for the MIT-licensed packages — the parts of ShoutKit built to be adopted outside this app. Feature code, the app target, and GPL-licensed packages (Packages/Features/*, Packages/LiveActivity) aren't part of this surface; see the Licensing table in README.md.

  • DesignSystem

    Liquid Glass-aware SwiftUI surfaces and design tokens — station rows/cards/carousel, artwork, playing indicator.

  • RadioDirectory

    Domain models, the RadioDirectoryProviding boundary, the Radio-Browser and SHOUTcast clients, curated/bundled directories.

  • Playback

    PlaybackController, the RadioPlaybackEngine seam, ICY metadata parsing, the sleep timer, and now-playing bridging.

  • PlaybackEngineAudioStreaming

    The production RadioPlaybackEngine, AVAudioEngine-backed via the AudioStreaming library.

  • Persistence

    SwiftData models and LibraryStore for favorites and recents.

  • FeatureFlags

    The feature-flagging seam used to gate work in progress across the app.

  • ImageIODownsample

    A leaf module wrapping ImageIO thumbnail decoding, so images never decode larger than the surface that draws them.

  • AudioLevels

    Live per-band audio levels from PCM, the tap plug-in protocol engines feed them through, and a SwiftUI meter.

Generated with DocC from each package's public API and merged into one cross-linked archive, so symbol references resolve across package boundaries. Rebuilt on every push that touches one of these packages — see build-docs.sh.
